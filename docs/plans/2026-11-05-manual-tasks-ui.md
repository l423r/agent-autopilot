# Ручные задачи в пульте: всё видно и отмечается кнопкой — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Когда автопилот ждёт человека (`[manual]`), пользователь видит в пульте, что именно сделать: текст шагов, рабочие ссылки (например, на видео для просмотра). Сделав, он нажимает галочку у шага, шаг отмечается в файле плана, автопилот продолжает сам. Сейчас ссылки приходится спрашивать у планировщика, а отмечать — тоже через него.

**Architecture:**
- **Пульт.** Блок «Ждёт вас» (вкладка «Статус») и задачи во вкладке «План» показывают полный текст ручной задачи (markdown, ссылки кликабельны, голые `https://…` тоже). У каждого неотмеченного шага `[manual]`-задачи — чекбокс. Новый `POST /api/tick` отмечает шаг в файле плана и коммитит файл в репозиторий проекта. Демон подхватит отметку сам: перепроверка `waiting-user` раз в 60 с уже есть (план queue-fixes).
- **Уведомление** «Ждёт вас» содержит ссылки из текста задачи и кнопку «Открыть в пульте».
- **Правило для планов.** Ручная задача сама говорит, что делать и где. Ссылку, которая появится только при выполнении (опубликованное видео, адрес выкладки), дописывает в текст ручной задачи предыдущая задача, которая её создаёт.

**Tech Stack:** Node 22, `node:test`; `web/server.mjs`, `web/index.html`, `web/markdown.mjs`, `lib/plan.mjs`, `lib/notify.mjs`.

**Spec:** просьба пользователя 2026-11-05: «когда требуется что-то ручное от меня, я этого не вижу… ссылки я не вижу на видео… хочется, чтоб я видел то, что мне нужно сделать, прям подробно в плане, и когда посмотрел, нажимаю кнопку (или чекбокс) и пункт плана становится выполненным».

## Global Constraints

- `POST /api/tick` `{ project, plan, task, step }` (`step` — номер галочки в задаче, с 1). Отмечает только неотмеченную галочку задачи `[manual]` (не `[planner]` и не обычной), только в плане из списка проектов (`findPlan`, путь из запроса до диска не доходит). Иначе — 400/404/409 с понятным текстом. Снять отметку нельзя.
- Запись атомарная: прочитать, проверить, что строка всё ещё `- [ ]` (иначе 409 «Уже отмечено»), заменить только `[ ]` → `[x]` в этой строке, записать через временный файл и `rename`. Остальной текст файла байт в байт тот же.
- Коммит: `git -C <projectDir> commit -m "docs: <Task N> отмечена в пульте" -- <planPath>` (только файл плана; если репозитория нет или коммит не удался — отметка остаётся, ответ `{ ok: true, commit: false, error }`, строка в лог демона). Автор — из конфига git репозитория.
- Ответ — `{ ok: true, taskDone: bool, commit: bool }`. После отметки пульт перерисовывает план и «Ждёт вас»; если задача стала выполненной — надпись «Отмечено, автопилот продолжит в течение минуты».
- Отображение: в «Ждёт вас» — заголовок задачи и полный текст с markdown, раскрыто по умолчанию, у каждого неотмеченного шага — чекбокс (крупный, для пальца, ≥ 32 px) и кнопка «Есть замечания». Она открывает чат с заготовкой `@<проект> <Task N> «<название>»: замечания — ` и не отмечает шаг. Во вкладке «План» у шагов `[manual]` — такие же чекбоксы; у остальных задач — только просмотр, как сейчас.
- `markdown.mjs`: голые `http(s)://…` становятся ссылками (`target="_blank" rel="noopener"`), не ломая `[текст](url)` и картинки; экранирование как сейчас (XSS-тесты).
- Уведомление «Ждёт вас» (ntfy): до 3 ссылок из текста задачи — в тексте сообщения, кнопка `view` «Открыть в пульте» на `webPublicUrl` (если задан) — с учётом лимита в 3 кнопки (заменяет наименее важную).
- Правило для планов: в `README.md` (раздел про виды задач) и в инструкцию планировщика пульта (где описаны `[manual]`, `[planner]` — найти по тексту `[manual]` в `web/`) добавить: «`[manual]`-задача содержит, что сделать, где (ссылки) и как понять, что всё ок. Ссылку, которой нет на момент планирования, дописывает в текст ручной задачи та задача, которая её создаёт (обычно «Финальный артефакт»)».
- Службы `agent-autopilot` и `agent-autopilot-web` в задачах 1–6 не перезапускать (их перезапуск — задача 8). `git push` в задачах не делать. Журнал — `docs/plans/2026-11-05-manual-tasks-ui.progress.md`. Автор коммитов — L423R.

## Review Focus

1. `/api/tick` не даёт отметить не-ручную задачу, чужой файл, уже отмеченную галочку; гонка двух нажатий даёт одну отметку и один коммит.
2. Файл плана после отметки отличается ровно одним символом; план с CRLF и с галочками во вложенных списках обрабатывается верно (номер `step` совпадает с тем, что считает `parsePlan`).
3. Автоссылки не дают XSS (`javascript:`, кавычки, `<` в URL) и не ломают существующие ссылки и картинки.
4. Ошибка git не теряет отметку и не роняет сервер.
