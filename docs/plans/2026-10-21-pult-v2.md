# Пульт v2 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** В пульте: картинки в чате, `@проект` в сообщениях, подсказка ответа, лимиты Claude, вкладка «План» со всеми проектами и переключение автопилота на другой план; плюс 8 отложенных замечаний ревью v1.

**Architecture:** Список проектов — новое поле `projects` в `config.json`; активный план — `<stateDir>/active.json`, перекрывающий `projectDir/planPath/progressPath` из конфига (нет файла → старое поведение). Пульт переключает автопилот, записывая `<stateDir>/switch.json`; демон применяет запрос только между задачами. Картинки — `POST /api/upload` в `<stateDir>/web/uploads/`, путь уходит планировщику текстом. Подсказка — служебная последняя строка ответа планировщика. Лимиты — сервер пульта спрашивает `api.anthropic.com/api/oauth/usage`.

**Tech Stack:** Node 22 (`node:http`, `fetch`, `node:test`), ванильный HTML/JS, `playwright-core` (только скриншоты).

**Spec:** `docs/superpowers/specs/2026-10-21-pult-v2-design.md` (одобрено 2026-10-21). Основа — `docs/plans/2026-10-21-web-panel.md`.

## Global Constraints

- Все Global Constraints плана `2026-10-21-web-panel.md` в силе: сервер только `127.0.0.1`, авторизация — Caddy; без runtime npm-зависимостей; экранирование HTML до Markdown, без `innerHTML` с сырым текстом; один ответ планировщика одновременно; русский интерфейс, тёмная тема (`#14121f`, акцент `#7b3cff`), 360–430 px без горизонтальной прокрутки, кнопки ≥44 px; в HTML только относительные пути.
- План исполняет сам автопилот на этом же репозитории: каждая задача оставляет рабочими демон и пульт со старым `config.json` без `projects` и без `active.json`. Службы `agent-autopilot` и `agent-autopilot-web` в задачах 1–12 **не перезапускать**.
- `config.json` и `config.*.json` не в git (секреты). Живой `config.json` правится только в Task 10.
- Готовый план = все чекбоксы задач отмечены (`parsePlan(...).tasks.every(t => t.done)` и задач > 0). Файлы `*.progress.md` и `progressPath` проектов — не планы.
- Токен OAuth и загруженные картинки не попадают в git, логи, ntfy и браузер (кроме самих картинок пользователю).
- Тесты — `npm test` (`TZ=UTC node --test`), подделки Claude/ntfy — как в `test/web-server.test.mjs`. TDD: сначала падающий тест.
- Журнал прогресса — `docs/plans/2026-10-21-pult-v2.progress.md`. Автор коммитов — L423R.

## Review Focus

1. Нажатие «Запустить», пока автопилот выполняет задачу: задача доходит до конца на старом плане, затем демон переключается; повторное нажатие на другой план заменяет запрос, а не ставит два. (тест — Task 4)
2. Путь к плану/проекту/картинке из запроса (`../`, абсолютный путь, чужое расширение) не выходит за `plansDir` проекта / папку загрузок → 400/404. (тесты — Task 5, Task 7)
3. Эндпоинт лимитов вернул 401 / не-JSON / другой формат или нет `.credentials.json` → «Нет данных о лимитах», остальные API работают. (тест — Task 9)
4. Ответ без строки-подсказки или со строкой не в конце: подсказки нет, текст ответа не теряется; служебная строка никогда не видна в чате. (тест — Task 8)
5. `@` с несуществующим именем, `@` в адресе почты, одно и то же `@имя` дважды: служебный блок только для реальных проектов, по одному разу. (тест — Task 6)
